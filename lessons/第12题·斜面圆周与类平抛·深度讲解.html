第 12 题 · 深度讲解

斜面内的圆周运动 ⊕ 斜面内的类平抛　｜　答案：BD
【原题】如图，倾角均为 30° 的两个光滑斜面体固定放置，两个斜面 ABCD、abcd 均是正方形，ABCD 的边长为 2L，abcd 的边长未知，a 是 CD 的中点，O 是 ABCD 的中心，a、C、b 在同一条直线上。质量为 m 的小球（视为质点）用长为 L 的轻质细线系于 O 点，在 a 点给小球一个沿 ab 方向、大小为 va = 2√(gL) 的初速度，绕 O 点在斜面内做圆周运动。当小球再次运动到 a 点时，突然剪断细线（不影响小球速度），此后小球沿斜面 abcd 运动并从 c 点离开。重力加速度为 g，不计空气阻力。下列说法正确的是（多选）

A．剪断细线前，小球在 a 点时细线的拉力大小为 4mg
B．小球在 c 点的速度大小为 2√(5gL)
C．abcd 的边长为 14L
D．剪断细线后，小球从 a 到 c 的运动时间为 8√(L/g)

第一步｜看懂这道题在考什么

题干很长，但骨架只有两段运动：

阶段发生什么物理模型
① a → 绕 O 一圈 → a细线拴着小球在光滑斜面内做圆周运动"竖直平面内圆周运动"的等效版（把 g 换成 g sin30°）
② a → c剪断线后在第二个光滑斜面上滑动类平抛：沿 ab 匀速 + 沿 ad 匀加速

两段的共同钥匙是同一个：光滑斜面上，物体只受沿斜面向下的 mg·sinα 这一个"有效重力"。

一句话通法：光滑斜面内的一切运动（圆周、类平抛、单摆…），把课本公式里的 g 换成 g·sinα，其余一字不改。本题 α = 30°，所以 g′ = g/2。

第二步｜把几何关系抠清楚（本题最大的门槛）

内切于正方形， 　切点正是四边中点 ② a 是 CD 中点 ⟹ Oa ⊥ CD 　⟹ va 沿 CD 恰为切线 ✓

要抠出来的三条几何事实

  • 圆恰好内切于正方形。边长 2L、半径 L、圆心在中心 ⟹ 圆与四条边相切，切点是各边中点。a 就是 CD 边上的切点。
  • 初速度确实是切线方向。a、C、b 共线，而 a 是 CD 的中点，所以"直线 aCb"就是 CD 边所在的直线；又因 Oa ⊥ CD，故沿 ab 方向的 va 垂直于半径 Oa —— 正是圆周运动要求的切线方向。
  • a 是圆周上的"最低点"。由图，AD、BC 沿最大坡度线（与水平面成 30°），AB、CD 是水平边。O 在 a 的正上坡方向、相距 L，所以沿斜面方向 a 比 O 低，是整个圆周的最低点（实际竖直高度差 = L·sin30° = L/2）。
这里就是 A 项设的陷阱。很多同学看到 a 在"图的下面"，却忘了追问"a 到底是不是圆周的最低点"，或者认定是最低点后又忘了写重力分量，于是只写 T = mv²/L = 4mg，正中出题人下怀。

第三步｜A 项：a 点细线的拉力

为什么小球回到 a 点时速度还是 va？斜面光滑、绳的拉力始终垂直于速度不做功，小球从 a 出发绕一圈回到同一点 a，高度没变 ⟹ 机械能守恒 ⟹ 速率不变，仍是 2√(gL)。所以剪线前后这一刻的受力分析可以直接用 va。

T − mg·sin30° = m·va² / L
T = m·(2√gL)² / L + 0.5mg = 4mg + 0.5mg = 4.5mg

A 项错误。

顺带一验：小球能转完整圈吗？最高点在 O 的上坡方向 L 处，与 a 的"等效高度差"为 2L：
v顶² = va² − 2g′·(2L) = 4gL − 2·(g/2)·2L = 2gL；
而"过顶"临界条件是 v顶² ≥ g′L = 0.5gL。因 2gL > 0.5gL，小球顺利通过最高点，能回到 a 点 ✓

第四步｜剪断细线后：一个漂亮的"类平抛"

为什么"从 c 点离开"就等于"走了正方形的对角线"？

剪线瞬间小球速度仍为 va，方向沿 ab（第二个正方形的上边）。进入第二个斜面后：

  • 沿 ab 方向（水平、垂直于最大坡度线）：不受力 ⟹ 匀速，速度恒为 va；
  • 沿 ad 方向（最大坡度线、向下坡）：加速度 g′ = g/2 ⟹ 初速为零的匀加速。

两方向垂直，标准的类平抛。小球从顶点 a 出发，"从 c 点离开"意味着它恰好到达对角顶点 c，所以两个方向的位移都等于边长 s。

D 项：运动时间

沿 ab：s = va·t　　　沿 ad：s = ½·g′·t² = ½·(g/2)·t² = g t²/4

两式相等（都等于 s），消去 s：

va·t = g t²/4　⟹　t = 4va/g = 4 × 2√gL / g
t = 8√gL/g = 8√L/g　D 项正确

化简技巧：√(gL)/g = √(gL/g²) = √(L/g)。

C 项：正方形 abcd 的边长

s = va·t = 2√gL × 8√L/g = 16·√gL · L/g = 16L　C 项错误（不是 14L）

B 项：c 点的速度大小

解法一（直接算分量）：

v∥ = va = 2√gL　（沿 ab，一直没变）
v⊥ = g′·t = (g/2) × 8√L/g = 4√gL　（沿 ad）
vc = √(2√(gL))² + (4√(gL))² = √4gL + 16gL = √20gL = 2√5gL　B 项正确

解法二（用平抛黄金比例，秒杀）：平抛/类平抛中

tanθ速度 = 2 · tanα位移

位移沿正方形对角线，tanα = s/s = 1 ⟹ tanθ = 2 ⟹ v⊥ = 2v∥ = 4√(gL)，同样得 vc = √5·v∥ = 2√(5gL)。

解法三（能量校验，强烈推荐用来查错）：光滑斜面，只有重力沿斜面的分量做功：

W = mg·sin30°·s = mg × 0.5 × 16L = 8mgL
½mvc² − ½mva² = ½m(20gL − 4gL) = 8mgL　✓ 完全吻合
最终答案：BD　（A 应为 4.5mg；C 应为 16L）

第六步｜可迁移的方法与易错清单

三条能带走的结论

  • 等效重力法：光滑斜面（倾角 α）内的运动 ⟺ 竖直平面内的运动，只需 g → g sinα。圆周运动的"最高点临界条件"也随之变为 v顶² ≥ g sinα · R。
  • 类平抛"落到对角"模型：若两方向位移相等（比值 1:1），则 t = 2v₀/a′，速度分量比恒为 2:1，末速度 = √5·v₀。这个结构在"平抛落到 45° 斜面"里一模一样地出现。
  • 位移偏角与速度偏角：tanθ速度 = 2·tanα位移，平抛、类平抛通用，能省掉大量计算。
易错清单（按踩坑频率排序）：
  1. 圆周最低点只写 T = mv²/R，漏掉 mg sinα（A 项）。
  2. 忘了把 g 换成 g sinα，直接用 g 算类平抛，时间和边长全错。
  3. 误以为"再次回到 a 点"速度会变小（其实斜面光滑，绳张力不做功，速率不变）。
  4. 看不出"从 c 点离开"= 走完对角线，两方向位移都是 s。
  5. √(gL)、√(L/g) 的化简出错——记住 √(gL)/g = √(L/g)。
变式自测：若把第二个斜面的倾角改成 53°（第一个仍 30°、va 不变），abcd 的边长和 c 点速度分别是多少？
提示：g′ = g sin53° = 0.8g，t = 2va/g′ = 5√(L/g)，s = vat = 10L，vc = √5·va = 2√(5gL)（末速度大小与倾角无关，因为位移比恒为 1:1！）。
