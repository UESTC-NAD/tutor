设复数 z = i1+i，则复数 z 的共轭复数 z̄ 在复平面内对应的点位于

A. 第一象限B. 第二象限C. 第三象限D. 第四象限
答案D

推导

  • 分母实数化，分子分母同乘 1−i：
    z = i(1−i)(1+i)(1−i) = i − i²1 − i² = 1 + i2 = 12 + 12i
  • 取共轭：z̄ = 12 − 12i，对应点 (1/2, −1/2)
  • 横坐标为正、纵坐标为负 ⟹ 第四象限
易错点　问的是 z̄ 不是 z。z 在第一象限，共轭后关于实轴翻折才落到第四象限。

如图，正方体 ABCD-A1B1C1D1 的棱 AB，BC，CD，CC1 所在的直线中，与直线 BC1 成异面直线的是

A. 直线 ABB. 直线 BCC. 直线 CDD. 直线 CC1
答案C

逐项判断

  • A. AB：AB 与 BC1 都过点 B ⟹ 相交，不是异面。
  • B. BC：同样都过点 B ⟹ 相交。
  • D. CC1：都过点 C1 ⟹ 相交。
  • C. CD：CD 与 BC1 无公共点；又 CD∥AB，而 AB 与 BC1 相交且不平行，故 CD 与 BC1 不平行 ⟹ 异面。

下图是正方体的平面展开图，关于这个正方体，下列判断不正确的是

A. BM ∥ DE B. CN ∥ 平面 AFB C. ED 与 NF 所成的角为 60° D. EN ∥ BC
答案A

第一步：把展开图折成正方体

  • 取中间一行的第 2 个正方形（顶点 A、B、C、D）作底面，其余五个面向上折。
  • 左侧正方形绕 AD 折起，E 落到 A 的正上方；下方正方形绕 AB 折起，F 落到 B 的正上方；上方正方形绕 DC 折起，N 落到 D 的正上方；右侧正方形绕 BC 折起，M 落到 C 的正上方；最右一个正方形恰好合成顶面。
  • 结论：得到正方体 ABCD-EFMN，即 E↔A，F↔B，M↔C，N↔D 上下对应。

第二步：建系验证（棱长取 1）

A(0,0,0)　B(1,0,0)　C(1,1,0)　D(0,1,0)
E(0,0,1)　F(1,0,1)　M(1,1,1)　N(0,1,1)

  • A. BM ∥ DE —— 不正确 ✗
    BM = M − B = (0, 1, 1)，DE = E − D = (0, −1, 1)。
    两向量不成比例 ⟹ 不平行；又 BM ⊂ 平面 BCMF（x=1），DE ⊂ 平面 ADNE（x=0），两平面平行且不重合，故二者无公共点 ⟹ BM 与 DE 是异面直线。
  • B. CN ∥ 平面 AFB —— 正确 ✓
    平面 AFB 即侧面 ABFE（y=0）。连 BE：BE = (−1, 0, 1) = CN，故 CN ∥ BE；
    而 BE ⊂ 平面 AFB，CN ⊄ 平面 AFB，由线面平行判定定理得 CN ∥ 平面 AFB。
  • C. ED 与 NF 所成角为 60° —— 正确 ✓
    ED = (0, 1, −1)，NF = (1, −1, 0)，均为面对角线，长度都是 √2。
    cosθ = |ED·NF||ED||NF| = |0 − 1 + 0|√2 · √2 = 12 ⟹ θ = 60°。
  • D. EN ∥ BC —— 正确 ✓
    EN = (0, 1, 0) = BC，方向相同；且 EN 与 BC 不重合（一条在 z=1、x=0，另一条在 z=0、x=1）⟹ 平行。
    也可直接看出 BCNE 是正方体的对角面（矩形），EN 与 BC 是它的一组对边。
命题陷阱　本题 A 项是经典易错点：由 BM = AN 知 BM ∥ AN，而 AN ⊂ 平面 ADNE，所以 BM ∥ 平面 ADNE 成立 —— 但 DE 只是这个平面内的一条直线，线面平行推不出线线平行。把"平行于平面"误当成"平行于面内每条直线"，就会误判 A 为正确。

已知复数 z = 2 − 3i，其中 i 是虚数单位，则下列结论正确的是

A. z 的模等于 13 B. z 在复平面内对应的点位于第四象限 C. z 的共轭复数为 −2 − 3i D. 若 z(m + 4i) 是纯虚数，则 m = −6
答案BD

逐项判断

  • A ✗　|z| = √2² + (−3)² = √13，不是 13。（模是带根号的）
  • B ✓　对应点 (2, −3)，横正纵负 ⟹ 第四象限。
  • C ✗　共轭只改虚部符号：z̄ = 2 + 3i。（实部不变！）
  • D ✓　z(m + 4i) = (2 − 3i)(m + 4i) = 2m + 8i − 3mi − 12i² = (2m + 12) + (8 − 3m)i
    纯虚数要求 实部为 0 且虚部不为 0：
    2m + 12 = 0 ⟹ m = −6；此时虚部 8 − 3(−6) = 26 ≠ 0 ✓
易错点　D 项若只解实部为零而忘记检验虚部非零，遇到"虚部恰好也为 0"的题就会出错。纯虚数两个条件缺一不可。

A. 甲旅游景区日均气温的中位数与平均数相等 B. 甲旅游景区的日均气温比乙旅游景区的日均气温稳定 C. 乙旅游景区日均气温的极差为 2 ℃ D. 乙旅游景区日均气温的众数为 5 ℃
答案ACD

先读数

日期1234567合计
甲536375635
乙546554635

  • A ✓　甲的平均数 x̄甲 = 357 = 5；
    甲从小到大排列：3, 3, 5, 5, 6, 6, 7，共 7 个数，第 4 个为中位数 = 5。
    二者都等于 5，相等。

如图，在圆台 O1O2 的轴截面 ABCD 中，AB = BC = AD = 12CD，CD = 4，则

A. 该圆台的高为 1 B. 该圆台轴截面面积为 3√3 C. 该圆台的体积为 7√3π/3 D. 一只小虫从点 C 沿着该圆台的侧面爬行到 AD 的中点，所经过的最短路程为 5
答案BCD

基本量

  • CD = 4 ⟹ AB = BC = AD = 2。轴截面 ABCD 是上底 2、下底 4、腰 2 的等腰梯形。
  • 上下底半径：r上 = 1，r下 = 2；两底水平差 4 − 22 = 1
  • 高 h = √2² − 1² = √3　⟹ A 错（高不是 1，1 是水平投影）

逐项判断

  • B ✓　梯形面积 = 12(2 + 4)·√3 = 3√3
  • C ✓　圆台体积 V = 13πh(r上² + r上r下 + r下²)
    = 13π·√3·(1 + 2 + 4) = 7√3π3
  • D ✓　补形 + 展开：
    设圆台补成圆锥后顶点为 O，母线 OA = l₁，OD = l₂。由相似 l₁l₂ = r上r下 = 12，又 l₂ − l₁ = AD = 2 ⟹ l₁ = 2，l₂ = 4。
    下底圆周长 = 2π·2 = 4π，展开成以 O 为心、半径 4 的扇形，圆心角 α = 4π4 = π（即 180°）。
    C、D 是下底圆的一条直径的两端（相差半个圆周），故展开后 ∠COD = π2 = 90°。
    AD 的中点到顶点 O 的距离 = 2 + 42 = 3。
    最短路程 = √4² + 3² = 5
方法　"沿侧面爬行的最短路径"必须先展开成平面图形，再用两点之间线段最短。圆台要先补成圆锥才能展成扇形；注意圆心角要由底面圆周长 = 扇形弧长算出，不能想当然。

某校高二年级从甲、乙两个班各选出 10 名学生参加数学竞赛，他们取得的成绩从低到高排列如下：
甲班：74　75　76　81　84　m　88　92　97　98
乙班：79　79　80　82　83　n　91　91　96　98
其中甲班学生成绩的平均分是 85，乙班学生成绩的中位数是 86，则 m + n 的值为 ______．

答案174

推导

  • 求 m（用平均数）：10 个数总和 = 85 × 10 = 850
    已知 9 个数之和 = 74+75+76+81+84+88+92+97+98 = 765
    m = 850 − 765 = 85　（检验：84 ≤ 85 ≤ 88，符合"从低到高"✓）
  • 求 n（用中位数）：10 个数为偶数个，中位数是第 5、6 两个数的平均：
    83 + n2 = 86 ⟹ n = 89　（检验：83 ≤ 89 ≤ 91 ✓）
  • m + n = 85 + 89 = 174
易错点　偶数个数据的中位数是中间两个数的平均；数据已按从低到高排好，求出的 m、n 必须落在相邻两数之间，一定要回代检验。

圆柱的高为 1，它的两个底面在直径为 2 的同一球面上，则该圆柱的体积为 ______．

答案3π/4

推导

  • 球的直径为 2 ⟹ 球半径 R = 1。
  • 圆柱两底面圆都在球面上 ⟹ 圆柱与球同轴、球心在圆柱轴的中点，球心到每个底面的距离 = 12·1 = 12。
  • 作轴截面，由勾股定理：r² + (12)² = R² = 1 ⟹ r² = 34
  • V = πr²h = π · 34 · 1 = 3π4
易错点　题给的是直径 2，不是半径；另外只需 r²，不必开方。

设 a = (cos θ, 1)，b = (cos θ, sin θ)，则 a·b 的最大值是 ______．

答案5/4

推导

  • 坐标法算数量积：a·b = cosθ·cosθ + 1·sinθ = cos²θ + sinθ
  • 统一为一个三角函数：cos²θ = 1 − sin²θ
    ⟹ a·b = 1 − sin²θ + sinθ
  • 换元 t = sinθ ∈ [−1, 1]，得二次函数
    f(t) = −t² + t + 1 = −(t − 12)² + 54
  • 开口向下，对称轴 t = 12 ∈ [−1, 1]，故 t = 12 时取最大值 54
方法　"三角 + 最值"的通用套路：先用平方关系把 sin、cos 统一成同一个量，再换元转化为闭区间上的二次函数问题。务必检查对称轴是否落在 t 的取值范围内。

(13 分) 在锐角三角形 ABC 中，A，B，C 的对边分别为 a，b，c，且 √3a = 2c·sin A．
(1) 求角 C 的大小．
(2) 若 c = √7，且 ab = 6，求 △ABC 的周长．

答案(1) C = π/3　(2) 5 + √7

(1) 求角 C

  • 已知条件中 a、c 是边，sin A 是角，考虑正弦定理边化角：
    由 asin A = csin C 得 a = 2Rsin A，c = 2Rsin C
  • 代入原式：√3·2Rsin A = 2·2Rsin C·sin A
  • A ∈ (0, π/2) ⟹ sin A ≠ 0，两边约去 2Rsin A：
    √3 = 2sin C ⟹ sin C = √32
  • 因为是锐角三角形，C ∈ (0, π/2)，舍去 C = 2π3，得 C = π/3

(2) 求周长

  • 余弦定理：c² = a² + b² − 2ab·cos C
  • 代入 c² = 7，ab = 6，cos π3 = 12：
    7 = a² + b² − 2 × 6 × 12 = a² + b² − 6
  • ⟹ a² + b² = 13
  • 凑完全平方：(a + b)² = a² + b² + 2ab = 13 + 12 = 25
    a, b > 0 ⟹ a + b = 5
  • 周长 = a + b + c = 5 + √7
方法　已知 ab 与 c 求周长，不必分别解出 a、b。利用 (a+b)² = (a²+b²) + 2ab 整体代换，是解三角形中最常用的技巧。

(15 分) 某监测站点于 2025 年 3 月某日起连续 n 天监测空气质量指数(AQI)，数据统计如下表；频率分布直方图中只画出了 [0, 50) 一组．
(1) 求出 n，m 的值，并完成频率分布直方图．
(2) 由频率分布直方图，估计该组数据的平均数与中位数．
(3) 在空气质量指数分别属于 [50, 100) 和 [150, 200) 的监测数据中，用分层随机抽样的方法抽取 5 天，再从中任意选取 2 天，求事件 A = "两天空气都为良"发生的概率．

空气质量指数 /(μg/m³)[0,50)[50,100)[100,150)[150,200)[200,250]
空气质量等级优良轻度污染中度污染重度污染
天数2040m105

  • 直方图中 [0, 50) 一组的纵坐标（频率/组距）为 0.004，组距为 50，
    故该组频率 = 0.004 × 50 = 0.2
  • 该组频数为 20，由"频率 = 频数 ÷ 总数"：
    20n = 0.2 ⟹ n = 100
  • 各组天数之和为 n：20 + 40 + m + 10 + 5 = 100 ⟹ m = 25
  • 补全直方图各组纵坐标（频率 ÷ 组距）：
    [50,100)：40/10050 = 0.008　　[100,150)：25/10050 = 0.005

  • 平均数：用每组组中值乘以该组频率再求和
    x̄ = 25×0.2 + 75×0.4 + 125×0.25 + 175×0.1 + 225×0.05
    　 = 5 + 30 + 31.25 + 17.5 + 11.25 = 95
  • 中位数：先累计频率
    [0,50)：0.2　　[0,100)：0.2 + 0.4 = 0.6 > 0.5
    ⟹ 中位数落在 [50, 100) 内。
  • 设中位数为 x，需要在该组内再补足 0.5 − 0.2 = 0.3 的频率：
    0.2 + (x − 50) × 0.008 = 0.5 ⟹ x − 50 = 0.30.008 = 37.5
    x = 87.5

(3) 求概率

  • [50, 100) 有 40 天（良），[150, 200) 有 10 天（中度污染），共 50 天，按 40 : 10 = 4 : 1 分层抽 5 天：
    良：5 × 4050 = 4 天（记为 a1, a2, a3, a4）；中度污染：1 天（记为 b）
  • 从 5 天中任取 2 天，基本事件总数 C52 = 5×42 = 10
  • 事件 A："两天空气都为良"，即从 4 天良中取 2 天：C42 = 4×32 = 6
  • P(A) = 610 = 35
另解　也可用对立事件：取到 b 的概率 = C₄¹C₅² = 410 = 25，故 P(A) = 1 − 25 = 35。

(15 分) 如图，在边长为 2 的菱形 ABCD 中，∠ADC = 60°，现将 △ADC 沿 AC 边折叠到 △APC 的位置，使平面 APC ⊥ 平面 ABC．
(1) 求证：PB ⊥ AC．　(2) 求三棱锥 P-ABC 的体积．

答案(2) V = 1

预备：算出各边长

  • 菱形中 AD = DC = 2，∠ADC = 60° ⟹ △ADC 是等边三角形，AC = 2。
  • 折叠只改变 △ADC 的位置、不改变其形状，故 △APC 也是边长为 2 的等边三角形，PA = PC = AC = 2。
  • 又 AB = BC = 2，AC = 2 ⟹ △ABC 也是边长为 2 的等边三角形。

(1) 证明 PB ⊥ AC

  • 取 AC 的中点 O，连接 PO，BO，PB。
  • △APC 中 PA = PC，O 是 AC 中点 ⟹ PO ⊥ AC（等腰三角形三线合一）。
  • △ABC 中 BA = BC，同理 BO ⊥ AC。
  • PO ∩ BO = O，且 PO、BO ⊂ 平面 POB
    由线面垂直的判定定理：AC ⊥ 平面 POB。
  • 又 PB ⊂ 平面 POB，由线面垂直的性质得 PB ⊥ AC．　∎

(2) 求体积

  • 找高。已证 PO ⊥ AC，且 PO ⊂ 平面 APC；
    又平面 APC ⊥ 平面 ABC，两平面交线为 AC，
    由面面垂直的性质定理得 PO ⊥ 平面 ABC，即 PO 就是三棱锥的高。
  • 等边 △APC 的中线：PO = √32 × 2 = √3
  • 底面积：S△ABC = √34 × 2² = √3
  • V = 13 · S · h = 13 × √3 × √3 = 1
折叠问题要点　折叠时，折痕同侧的量（△APC 内部的边、角）全部不变，跨折痕的量（如 PB）会改变。本题中 PA = PC = 2 就是折叠前 DA = DC = 2 继承下来的。
另外"面面垂直 ⟹ 线面垂直"必须满足三个条件：直线在其中一个面内、垂直于交线、两面垂直，缺一不可。

(17 分) 某社区举行宪法宣传答题活动，共设置三关，选手从第一关开始依次闯关，若闯关失败或闯完三关，则闯关结束，规定每名选手只能参加一次活动．已知每名选手第一关闯关成功的概率为 45，第二关为 12，第三关为 25．规定闯关结束时，恰好通过两关可获得奖金 300 元，三关全部通过可获得奖金 800 元．假设选手是否通过每一关相互独立．
(1) 求参加活动的选手没有获得奖金的概率．
(2) 现有甲、乙两名选手参加本次活动，求两人最后所得奖金总和为 1100 元的概率．

答案(1) 3/5　(2) 48/625

预备：四种结局及其概率

记 Ai = "第 i 关通过"，则 P(A1) = 45，P(A2) = 12，P(A3) = 25，且相互独立。

结局概率计算概率奖金
第一关就失败1 − 4/51/5 = 5/250
恰过 1 关(4/5)(1 − 1/2)2/5 = 10/250

检验：5/25 + 10/25 + 6/25 + 4/25 = 1 ✓

(1) 没有获得奖金的概率

  • "没有获得奖金"即通过的关数不超过 1，包含两个互斥事件：
  • 第一关失败：P = 1 − 45 = 15
  • 过第一关但第二关失败：P = 45 × (1 − 12) = 25
  • 互斥事件概率相加：P = 15 + 25 = 35

(2) 两人奖金总和为 1100 元

  • 单人奖金只可能是 0、300、800 三种。要凑出 1100，只有一种拆法：
    1100 = 300 + 800（因为 0 + 1100、800 + 300 之外无其他组合）
  • 即"一人得 300，另一人得 800"，包含两个互斥情形：
    ① 甲 300、乙 800　② 甲 800、乙 300
  • 由上表：P(得 300) = 625，P(得 800) = 425
  • 两人相互独立：
    P = 2 × 625 × 425 = 48625 = 48625

(17 分) 如图，在四棱锥 P-ABCD 中，四边形 ABCD 是边长为 2 的正方形，AC 与 BD 交于点 O，PA ⊥ 平面 ABCD，且 PA = 2．
(1) 求证：BD ⊥ 平面 PAC．　(2) 求直线 PD 与平面 PAC 所成角的大小．

答案(2) 30°（即 π/6）

(1) 证明 BD ⊥ 平面 PAC

  • PA ⊥ 平面 ABCD，而 BD ⊂ 平面 ABCD
    ⟹ PA ⊥ BD（线面垂直的性质）
  • ABCD 是正方形，对角线互相垂直
    ⟹ AC ⊥ BD
  • PA ∩ AC = A，且 PA、AC ⊂ 平面 PAC
    由线面垂直的判定定理：BD ⊥ 平面 PAC．　∎

(2) 求线面角

  • 找射影。由 (1) 知 DO ⊥ 平面 PAC（O 是垂足），
    所以 D 在平面 PAC 内的射影就是 O，PO 是 PD 的射影，
    ∠DPO 即为直线 PD 与平面 PAC 所成的角。
  • 算长度。正方形边长 2 ⟹ 对角线 BD = 2√2，
    DO = 12BD = √2
  • PA ⊥ 平面 ABCD ⟹ PA ⊥ AD，在 Rt△PAD 中：
    PD = √PA² + AD² = √4 + 4 = 2√2
  • 由 DO ⊥ 平面 PAC ⟹ DO ⊥ PO，△DPO 是直角三角形：
    sin∠DPO = DOPD = √22√2 = 12
  • 线面角范围为 [0°, 90°] ⟹ ∠DPO = 30°
方法　求线面角的关键是找射影。本题第 (1) 问已经证出 BD ⊥ 平面 PAC，这就直接告诉我们 D 的射影是 O —— 前一问往往是后一问的钥匙，做题时要有意识地利用。

(17 分) 记 △ABC 的内角 A，B，C 的对边分别为 a，b，c，已知 △ABC 的面积为 √3，D 为 BC 的中点，且 AD = 1．
(1) 若 ∠ADC = π3，求 tan B．　(2) 若 b² + c² = 8，求 b，c．

答案(1) tan B = √3/5　(2) b = c = 2

(1) 求 tan B

  • 中线等分面积：D 是 BC 中点 ⟹ S△ABD = S△ADC = 12S△ABC = √32
  • 在 △ADC 中用面积公式求 DC：
    12·AD·DC·sin∠ADC = 12 × 1 × DC × √32 = √32
    ⟹ DC = 2，从而 BD = 2，a = BC = 4
  • ∠ADC = π3 ⟹ ∠ADB = π − π3 = 2π3（补角）
  • 在 △ABD 中用余弦定理求 AB：
    AB² = AD² + BD² − 2·AD·BD·cos2π3
    = 1 + 4 − 2 × 1 × 2 × (−12) = 7 ⟹ AB = √7
  • 再在 △ABD 中求 B：
    sinB（正弦定理）：ADsin B = ABsin∠ADB ⟹ sinB = 1 × √3/2√7 = √32√7
    cosB（余弦定理）：cosB = AB² + BD² − AD²2·AB·BD = 7 + 4 − 12 × √7 × 2 = 104√7 = 52√7
  • tan B = sin Bcos B = √3/(2√7)5/(2√7) = √35

(2) 求 b，c

  • 用中线长公式求 a：在 △ABD 与 △ADC 中对补角 ∠ADB、∠ADC 分别用余弦定理并相加，得
    AD² = 2b² + 2c² − a²4
  • 代入 AD = 1，b² + c² = 8：
    1 = 2 × 8 − a²4 ⟹ 4 = 16 − a² ⟹ a² = 12
  • 联立面积与余弦定理。由面积公式：
    12bc·sin A = √3 ⟹ sin A = 2√3bc
  • 由余弦定理：cos A = b² + c² − a²2bc = 8 − 122bc = −2bc
  • 由 sin²A + cos²A = 1：
    12(bc)² + 4(bc)² = 1 ⟹ (bc)² = 16 ⟹ bc = 4（bc > 0）
  • 联立 b² + c² = 8 与 bc = 4：
    (b − c)² = b² + c² − 2bc = 8 − 8 = 0 ⟹ b = c
  • 代回 bc = 4 ⟹ b² = 4 ⟹ b = c = 2
中线三大工具　遇到"中线 + 面积"的题，通常从三条路选：
① 面积等分：中线把三角形分成面积相等的两半（本题 (1)）；
② 补角关系：∠ADB + ∠ADC = π，故 cos∠ADB = −cos∠ADC；
③ 向量法：2AD = AB + AC，两边平方得 4AD² = b² + c² + 2bccosA，与中线长公式等价（本题 (2)）。
