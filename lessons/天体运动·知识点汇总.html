01开普勒三定律

三条定律

  1. 轨道定律：所有行星绕太阳运动的轨道都是椭圆，太阳处在椭圆的一个焦点上。
  2. 面积定律：对任意一个行星，它与太阳的连线在相等时间内扫过相等的面积。
    ⇒ 推论：近日点最快、远日点最慢；在近日点、远日点处速度垂直于矢径，有 r近v近 = r远v远。
  3. 周期定律：所有行星轨道半长轴的三次方与公转周期的二次方的比值都相同： a3T2 = k。

公式推导 · 开普勒常量 k 与面积定律推论

①由圆轨道推出 k 的表达式。设中心天体质量 M，环绕体质量 m、轨道半径 r、周期 T。万有引力提供向心力：

GMmr2 = m4π2T2r

②两边约去 m，再把 r、T 归到同一侧：

GMr2 = 4π2rT2  ⇒  GMT2 = 4π2r3

r3T2 = GM4π2 ≡ k

③椭圆情形。把 r 换成半长轴 a，结论形式不变：a3/T2 = GM中/(4π2)。式中只出现中心天体质量 M中与常量 G、π —— 这就是“k 只由中心天体决定”的根源。

④面积定律的定量形式。极短时间 Δt 内，连线扫过的图形近似为三角形（底 = vΔt，此边上的高 = rsinθ，θ 为 v 与矢径的夹角）：

ΔS = 12r·vΔt·sinθ  ⇒  ΔSΔt = 12rvsinθ = 常量

⑤在近日点与远日点，速度恰好垂直于矢径（sinθ = 1），代入上式得：

12r近v近 = 12r远v远  ⇒  r近v近 = r远v远

⑥由 ② 反解，即得估算中心天体质量的公式（见第 05 板块）：M中 = 4π2a3/(GT2)。

使用要点

  • 圆轨道是椭圆的特例，此时 a = r，k 的形式不变。
  • k 只由中心天体质量决定：绕太阳的用太阳的 k，绕地球的用地球的 k，两者不能画等号（对应讲义第 1 题）。
  • 转移椭圆的半长轴 = (近地点半径 + 远地点半径)/2（对应讲义第 5 题）。

02万有引力定律与球壳定理

F = Gm1m2r2，  G = 6.67×10−11 N·m2/kg2

  • 适用条件：两个可视为质点的物体；或均匀球体（此时 r 取两球心之间的距离）。
  • 球壳定理：均匀球壳对壳内任意位置的物体引力为零。
  • 由球壳定理可得，均匀球体内部距球心 r 处：只有半径 r 的“内球”有贡献， M′ = M·r3R3，于是 F = GM′mr2 = GMmR3r ∝ r，即 球内引力与 r 成正比。

为什么球壳定理成立（两步论证 · 选讲）

一、“面元质量 ∝ r²”从哪来？这句话要拆成两步（见图 3）：

  1. 圆锥相似放大：从 P 点张开一个张角固定的小圆锥，它在距 P 为 r 处截出的圆面，半径由相似三角形决定，与 r 成正比 ⇒ 面积 S ∝ r2。（同“手电筒照得越远、光斑越大”是一回事。）
  2. 两端倾角相同：球壳上的面元是斜切下来的，斜切把面积放大 1/cosθ 倍。关键在于 OA = OB = R ⇒ △OAB 等腰 ⇒ ∠OAB = ∠OBA = θ；而 OA、OB 正是球面在两处的法线，故两端倾角完全相同，放大因子可以约掉。

于是 S = Ωr2/cosθ，面密度 σ 均匀 ⇒ m = σS ∝ r2。代入万有引力（m0 为壳内物体质量）：

F = Gm0mr2 = Gm0σΩr2r2cosθ = Gm0σΩcosθ　—— 与 r 无关

分母的 r² 被质量带来的 r² 约掉了：远处的面元虽然远（引力削弱 r² 倍），但同时也大（质量增大 r² 倍），一削一补恰好抵平 ⇒ F1 = F2、方向相反而抵消 ⇒ 全壳合力为零。

二、“厚外壳整体贡献为零”又从哪来？把从半径 r 到 R 的厚外壳，像剥洋葱一样切成无数层同心薄球壳。深度 d 处的物体恰好位于每一层薄壳的内部，由上一条，每层引力都为零：

0 + 0 + 0 + … = 0

零累加仍是零 ⇒ 外壳整体合力为零，只剩“脚下半径 r 的实心内球”在起作用。

课堂一句话版：远的更远，但也更大；远得刚好被大得抵平。  洋葱一层层剥，每层都是零，加起来还是零。

公式推导 · 球体内部与外部的 g

①均匀球体密度 ρ = M/[(4/3)πR3]。距球心 r（r ≤ R）处，由球壳定理只有半径 r 的内球有效：

M′ = ρ·43πr3 = M(4/3)πR3·43πr3 = Mr3R3

②该处物体受到的引力：

F = GM′mr2 = G(Mr3/R3)mr2 = GMmR3·r

F ∝ r  （球心处为零，表面处最大）

③两边除以 m 得该处重力加速度，再用表面值 g0 = GM/R2 化简：

g′ = GMR3r = GMR2·rR = g0rR

④用深度 d 表示（r = R − d）：

g′ = g0R − dR  （内部：线性下降）

⑤球体外部（r = R+h > R）则要用整个球的质量：

g′ = GM(R+h)2 = g0R2(R+h)2  （外部：平方反比）

03两条基本关系（“地上”与“天上”）

关系一：天体表面（忽略自转）

GMmR2 = mg  ⇒  GM = gR2（黄金代换）

作用：把不易测量的 G、M 换成容易测量的 g、R。凡题目给 g 和 R 却不给 G 和 M，一律先写这一步。

关系二：环绕天体（万有引力提供向心力）

GMmr2 = ma = mv2r = mω2r = m4π2T2r

04卫星运行参量与“越高越慢”

物理量表达式与 r 的关系记忆要点
线速度 vGMrv ∝ r−1/2半径大 → 速度小
角速度 ωGMr3ω ∝ r−3/2半径大 → 角速度小
周期 T2πr3GMT ∝ r3/2半径大 → 周期长
向心加速度 aGMr2a ∝ r−2半径大 → 加速度小

口诀：高轨低速大周期，低轨高速小周期（v、ω、a 同减，只有 T 增）

公式推导 · 四个环绕参量全部来自同一条式子

①出发点只有一条 —— 万有引力提供向心力，而向心力有四种等价写法：

GMmr2 = ma = mv2r = mω2r = m4π2T2r

②取 = ma：约去 m 得 a = GM/r2，即 a ∝ r−2。

③取 = mv2/r：GM/r2 = v2/r ⇒ v2 = GM/r ⇒

v = GMr  (v ∝ r−1/2)

④取 = mω2r：GM/r2 = ω2r ⇒ ω2 = GM/r3 ⇒

ω = GMr3  (ω ∝ r−3/2)

⑤取 = m(4π2/T2)r：GM/r2 = 4π2r/T2 ⇒ T2 = 4π2r3/(GM) ⇒

T = 2πr3GM  (T ∝ r3/2)

⑥若题目只给 g、R 而不给 G、M，把 GM = gR2 代进去即可：

v = Rgr， ω = Rgr3， T = 2πRr3g， a = gR2r2

⑦四个指数摆在一起，“越高越慢”就一目了然：r 增大时 v、ω、a 全部变小，只有 T 变大。

05天体质量与密度的估算

已知条件中心天体质量中心天体密度备注
环绕体的 r、T M = 4π2r3GT2 ρ = 3πr3GT2R3 求密度还需中心天体半径 R
近地环绕（r ≈ R）只给 T — ρ = 3πGT2 只需周期！最常考的秒杀式
表面 g、半径 R M = gR2G ρ = 3g4πGR 密度式别漏 G
双星的 L、T m1+m2 = 4π2L3GT2 — 只能得总质量，需另给条件才可拆分

公式推导 · 四类估算式逐条来历

①由环绕体的 r、T 求中心天体质量。万有引力提供向心力：

GMmr2 = m4π2T2r  ⇒  M = 4π2r3GT2

②再求密度。注意分母是中心天体自身的体积（半径 R，不是轨道半径 r）：

ρ = M(4/3)πR3 = 4π2r3GT2·34πR3 = 3πr3GT2R3

③近地退化。当环绕体贴近表面飞行时 r ≈ R，上式中 r3/R3 = 1：

ρ = 3πGT2  —— 只要一个周期就够了

④由表面 g、R 求质量。忽略自转时表面处引力等于重力：

GMmR2 = mg  ⇒  M = gR2G

⑤由表面 g、R 求密度。把 ④ 代入密度定义：

ρ = gR2/G(4/3)πR3 = gR2G·34πR3 = 3g4πGR

⑥以上每一步中，环绕体（或被称量物体）的质量 m 都被约掉了 —— 这就是“只能求中心天体质量”的原因。

三条铁律

  • 只能求中心天体的质量，环绕体质量必被约去。
  • 轨道半径 r = R + h，“距表面高度”绝不是轨道半径（讲义第 6 题）。
  • 密度公式记为 ρ = 3πr3/(GT2R3)，令 r = R 立刻退化为 3π/GT2，一式两用。

06三个宇宙速度

名称数值表达式物理意义
第一宇宙速度7.9 km/sv1 = GMR = gR最大环绕速度、最小发射速度（贴地飞行）
第二宇宙速度11.2 km/sv2 = 2v1挣脱地球引力束缚（脱离速度）
第三宇宙速度16.7 km/s—挣脱太阳引力束缚，飞出太阳系

卫星绕地运行的发射速度范围：7.9 km/s ≤ v发 < 11.2 km/s

公式推导 · 第一、第二宇宙速度是怎么算出来的

①第一宇宙速度：设想卫星贴着地面做圆周运动（r = R），引力全部作向心力：

GMmR2 = mv12R  ⇒  v1 = GMR

②用黄金代换 GM = gR2 消去 G、M：

v1 = gR2R = gR

③代数字（g = 9.8 m/s2，R = 6.4×106 m）：v1 = √(9.8×6.4×106) = √(6.27×107) ≈ 7.9×103 m/s

④第二宇宙速度：“恰好逃逸”＝飞到无穷远时速度恰好减为零。取无穷远处引力势能为零，机械能守恒：

12mv22 + (−GMmR) = 0 + 0

⑤解得：

v2 = 2GMR = 2·v1 = 1.414 × 7.9 ≈ 11.2 km/s

⑥两个速度一夹，就得到卫星发射速度的范围：7.9 km/s ≤ v发 < 11.2 km/s。低于 7.9 上不了天，达到 11.2 就飞出地球。

最高频误区

  • “发射速度必须大于 11.2 km/s” —— 错，超过就飞走了（讲义第 4 题 A 项）。
  • “卫星越高速度越大” —— 错，7.9 km/s 是上限，所有卫星运行速度都小于它。
  • 第一宇宙速度是“环绕速度的最大值”与“发射速度的最小值”，两个“最”方向相反，配套记忆。

07同步卫星与“三兄弟”比较

同步卫星的“五定一不定”

  • 周期一定：T = 地球自转周期 = 24 h
  • 角速度一定：ω = 7.3×10−5 rad/s
  • 轨道平面一定：必在赤道正上方（轨道平面与赤道平面重合）
  • 高度一定：h ≈ 3.6×104 km，轨道半径 r ≈ 6.6R地
  • 速率一定：v ≈ 3.1 km/s
  • 质量不定：与卫星自身质量无关

公式推导 · 同步卫星的高度、速率是算出来的，不是背出来的

①同步 ⇒ T ＝ 地球自转周期 ＝ 24 h ＝ 8.64×104 s。由万有引力提供向心力：

GMmr2 = m4π2T2r  ⇒  r3 = GMT24π2 = gR2T24π2

②代数字：gR2T2 = 9.8×(6.4×106)2×(8.64×104)2 ≈ 3.0×1024，再除以 4π2 ≈ 39.5：

r3 ≈ 7.6×1022 m3  ⇒  r ≈ 4.2×107 m ≈ 6.6R地

③高度：h = r − R = 4.2×107 − 0.64×107 ≈ 3.6×107 m = 3.6×104 km

④速率：v = 2πr/T = 6.28×4.2×107 / (8.64×104) ≈ 3.1×103 m/s

⑤角速度：ω = 2π/T = 6.28/(8.64×104) ≈ 7.3×10−5 rad/s

⑥为什么必须在赤道正上方？卫星做圆周运动，向心力是指向地心的万有引力 ⇒ 圆心必须是地心 ⇒ 轨道平面必过地心；又要与地面某点始终相对静止 ⇒ 轨道平面还必须与赤道平面重合。两条一夹，只剩赤道正上方一个圆。

⑦“三兄弟”关系的推法。a（赤道物体）与 c（同步卫星）同 ω，用 v = ωr、a = ω2r（半径大者大）；b（近地卫星）与 c 同为卫星，用 v = √(GM/r) 一族（半径大者小）。以 c 为桥梁串起来：

ωb > ωc = ωa，  vb > vc > va，  Tb < Tc = Ta，  ab > ac > aa

08变轨、离心近心与能量

圆轨道上的能量关系

Ek = GMm2r， Ep = −GMmr， E = Ek+Ep = −GMm2r

  • r 增大：总机械能增大，但动能减小（升轨要“花钱”，结果却更慢）。
  • 受阻力时 E 减小 ⇒ r 减小 ⇒ Ek 增大 ⇒ 速率变大。
  • 椭圆轨道上：近地点速率最大、加速度最大；远地点相反；全过程机械能守恒。

公式推导 · 能量表达式与离心/近心判据

①动能。圆轨道上 v2 = GM/r，代入动能定义：

Ek = 12mv2 = 12m·GMr = GMm2r

②势能。取无穷远处为零势能，引力势能 Ep = −GMm/r（由变力做功得到，高中直接引用）。

③总机械能。两者相加：

E = Ek + Ep = GMm2r − GMmr = −GMm2r

④由此可直接读出：r 增大 ⇒ E 增大（负得更少，要烧燃料），但 Ek = GMm/2r 减小 —— 升轨要花钱，结果却飞得更慢。

⑤离心 / 近心判据。设在半径 r 处速率被突然改成 v′，比较“做圆周运动所需的向心力”与“实际提供的引力”：

F需 = mv′2r，   F引 = GMmr2

v′ > GMr ⇒ F需 > F引 ⇒ 离心，r 增大（加速升轨）

v′ < GMr ⇒ F需 < F引 ⇒ 近心，r 减小（减速降轨）

⑥“越阻越快”的定量说明。阻力做负功 ⇒ E = −GMm/2r 减小 ⇒ r 减小 ⇒ Ek = GMm/2r 增大。换句话说：势能降了 2ΔEk，其中一半变成动能、一半被阻力耗掉。

⑦转移椭圆的时间。近地点 r1、远地点 r2 ⇒ 半长轴 a = (r1+r2)/2；由开普勒第三定律

T椭2a3 = T12r13 ⇒ T椭 = T1(r1+r2)38r13，转移时间 t = T椭2 = T1(r1+r2)332r13

变轨三判断

  1. 判方向：加速升轨、减速降轨。
  2. 判加速度：同一位置点上，无论在哪条轨道，a = GM/r2 都相同。
  3. 判速度：同一点上，外层轨道速度更大（因为是加速后才上去的）。

09双星与多星模型

双星模型

Gm1m2L2 = m1ω2r1 = m2ω2r2

m1 + m2 = 4π2L3GT2

  • 引力式的分母是星心距 L，向心力式用各自的轨道半径 r1、r2。
  • r1 + r2 = L，m1r1 = m2r2。
  • 把两式相加即消去 r1、r2，得总质量（讲义第 10 题）。

三星模型

类型轨道半径引力合力结论
直线型
（两星绕中央星）		 r = L 54Gm2L2 v = 125GmL，T = 4πL35Gm
三角型
（等边三角形）		 r = L2cos30° = 3L3 2·Gm2L2cos30° = 3Gm2L2 a = 3GmL2，ω = 3GmL3

公式推导 · 双星

①两星相距恒为 L，绕连线上同一点 O 转，周期、角速度必然相同（ω = 2π/T）。分别列式 —— 引力用星心距 L，向心力用各自的轨道半径：

Gm1m2L2 = m1ω2r1  ……①    Gm1m2L2 = m2ω2r2  ……②

②① 两边除以 m1，② 两边除以 m2：

Gm2L2 = ω2r1    Gm1L2 = ω2r2

③两式相加，右边恰好凑出 r1 + r2 = L：

Gm1+m2L2 = ω2(r1+r2) = ω2L

④代入 ω = 2π/T：G(m1+m2)/L2 = 4π2L/T2，整理得

m1 + m2 = 4π2L3GT2

⑤另一方面，①、② 左边完全相同，故 m1ω2r1 = m2ω2r2，约去 ω2：

m1r1 = m2r2  （质量大的离公共圆心 O 更近）

公式推导 · 直线三星与三角形三星

甲 · 直线三星

①外侧星受两个引力：来自中央星（距 L）与来自另一外侧星（距 2L），二者方向相同，都指向中央星（＝圆心），轨道半径 r = L：

F合 = Gm2L2 + Gm2(2L)2 = Gm2L2(1 + 14) = 54Gm2L2

②令 F合 = mv2/L，约去一个 m：

54GmL2 = v2L ⇒ v2 = 5Gm4L ⇒ v = 125GmL

③周期：

T = 2πLv = 2πL·2√(5Gm/L) = 4πLL5Gm = 4πL35Gm

④换一条路校验：令 F合 = m(4π2/T2)L ⇒ (5/4)Gm/L2 = 4π2L/T2 ⇒ T2 = 16π2L3/(5Gm)，开方与上式一致 ✓

乙 · 三角形三星

①先定轨道半径：三星在正三角形顶点上，圆心是外接圆圆心。取一条中线，半边长 L/2，与该顶点连线成 30°：

r = L/2cos30° = L2 × (√3/2) = L√3 = 3L3

②再求引力合力：每颗星受另两颗的引力，大小同为 Gm2/L2，二者夹角 60°，各与指向圆心的中线成 30°，故只有沿中线的分量留下：

F合 = 2·Gm2L2·cos30° = 2·Gm2L2·32 = 3Gm2L2

③加速度（直接除以质量，与轨道半径无关）：

a = F合m = 3GmL2

④角速度：令 F合 = mω2r，代入 r = L/√3：

3Gm2L2 = mω2·L3 ⇒ ω2 = 3·3GmL3 = 3GmL3

ω = 3GmL3  （前面没有系数 2）

⑤线速度与周期：

v = ωr = 3GmL3·L3 = GmL，  T = 2πω = 2πL33Gm

多星问题三步法

  1. 找圆心、定半径：直线型圆心在中央星，三角型圆心在外接圆中心（r = √3L/3）。
  2. 受力分析、求合力：把所有其他星对它的引力都算上，按几何关系合成。
  3. 合力 = 向心力：F合 = ma = mω2r = mv2/r = m(4π2/T2)r。

10重力与万有引力 · 赤道“飘起”

考虑地球自转时，物体所受万有引力分成两部分：一部分提供随地球自转所需的向心力，其余才是重力。

F引 = mg + mω2r纬（矢量式）  ⇒  两极 g 最大，赤道 g 最小

  • 两极：r纬 = 0，向心力为零，mg = GMm/R2，重力＝万有引力（大小、方向都一致）。
  • 赤道：GMm/R2 − mg = mω2R，重力最小，且重力与万有引力方向一致。
  • 一般纬度：重力方向不指向地心（略偏向赤道一侧）。

公式推导 · g 随纬度变化与临界自转周期

①纬度 φ 处的物体随地球自转做圆周运动，转动半径是 R cosφ（不是 R），所需向心力

Fn = mω2Rcosφ  （方向垂直指向自转轴）

②万有引力 F引 = GMm/R2 指向地心。重力是引力扣掉那一份向心力后剩下的：mg = F引 − Fn（矢量差，所以一般纬度重力不指向地心）。

③两极（φ = 90°）：cosφ = 0 ⇒ Fn = 0

mg极 = GMmR2 ⇒ g极 = GMR2  （最大，且重力＝万有引力）

④赤道（φ = 0°）：引力、向心力、重力三者共线，可写成代数式

GMmR2 − mg赤 = mω2R ⇒ g赤 = GMR2 − ω2R  （最小）

⑤数值感受：ω2R = (7.3×10−5)2×6.4×106 ≈ 0.034 m/s2，只有 g 的约 1/290 —— 所以平时可以忽略地球自转。

⑥临界“飘起”：赤道上支持力 N = 0，即 g赤 = 0，万有引力全部用作向心力：

GMmR2 = m4π2T2R

⑦题目只给密度，故把 M = ρ·(4/3)πR3 代入：

G·ρ(4/3)πR3R2 = 4π2RT2 ⇒ 43πGρR = 4π2RT2

⑧两边约去 R（这正是“与天体大小无关”的来源），解出 T：

T2 = 4π2(4/3)πGρ = 3πGρ ⇒ Tmin = 3πGρ， 反解 ρ = 3πGT2

⑨视重公式：弹簧测力计示数 N = F引 − Fn（该处所需的向心力）。绕行飞船中 Fn 恰好等于 F引 ⇒ N = 0，即完全失重 —— 但引力并不为零。

要点提醒

  • 临界周期 T = √(3π/Gρ) 与天体半径无关，只由密度决定；它与“近地卫星周期”是同一个式子。
  • 反解得 ρ = 3π/(GT2)，与“近地卫星测密度”完全一致 —— 两个考点其实是一个。
  • 完全失重指视重为零，物体依然受万有引力（它正是向心力的来源）。

11追及与相遇（会合周期）

会合周期：1T会 = 1T1 − 1T2  ⇒  T会 = T1T2T2 − T1  （T1 < T2）

公式推导 · 会合周期、最近与最远条件

①同向绕行，设 T1 < T2（内圈快）。t 时刻两者各自转过的角度：

θ1 = ω1t = 2πT1t，  θ2 = ω2t = 2πT2t

②两者拉开的角度差：

Δθ = (ω1 − ω2)t = 2π(1T1 − 1T2)t

③再次“最近”（回到同一方位）：内圈比外圈多转整数圈，Δθ = 2nπ

2π(1T1 − 1T2)t = 2nπ ⇒ t = n1/T1 − 1/T2 = n·T1T2T2 − T1

会合周期 T会 = T1T2T2 − T1， 即 1T会 = 1T1 − 1T2

④“最远”（转到同一直径的两端）：多转半圈的奇数倍，Δθ = (2n−1)π。第一次取 n = 1：

t′ = T1T22(T2 − T1) = 12T会

⑤追上给定的初始相位差 α：令 Δθ = α

t = αω1 − ω2 = αT1T22π(T2 − T1)  （α = π/3 时即 T1T26(T2 − T1)）

⑥反向绕行：相对角速度变成 ω1 + ω2，把上面所有的 (T2 − T1) 换成 (T1 + T2) 即可。

⑦极限检验：T1 → T2 时 T会 → ∞（两者步调一致，永不再相遇），与直觉相符。

交会对接的“反直觉”

追踪飞行器要与前方高轨目标对接，不能直接加速（加速会升轨反而变慢），正确顺序是：在低轨等待追上 → 再加速抬高轨道 → 对接。这与“加速升轨、升轨变慢”的规律完全自洽。

12易错清单与公式速查表

15 条易错清单（考前 3 分钟速览）

  1. 开普勒常量 k 只对同一中心天体成立，不同系统不能画等号。
  2. 轨道半径 r = R + h，“高度”不是“半径”。
  3. 密度公式 ρ = 3g/(4πGR)，别漏 G。
  4. 只能求中心天体的质量，环绕体质量必被约去。
  5. 第一宇宙速度 7.9 km/s：最大环绕速度 & 最小发射速度。
  6. 发射速度必须小于 11.2 km/s 才能成为地球卫星。
  7. 同步卫星只能定点在赤道正上方，不能在北京上空。
  8. 赤道上的物体不是卫星，不能套用 v = √(GM/r)。
  9. 比较向心加速度只看 r；比较向心力还要看质量。
  10. 变轨点上：加速度相同、速度不同。
  11. 转移椭圆半长轴 = (r1+r2)/2，转移时间取半个周期。
  12. 阻力使卫星机械能减小，但动能增大（越阻越快）。
  13. 双星：引力用星心距 L，向心力用各自半径；r1+r2 = L。
  14. 三角形三星的轨道半径是外接圆半径 √3L/3，不是边长 L。
  15. “完全失重”是视重为零，不是“不受引力”。
